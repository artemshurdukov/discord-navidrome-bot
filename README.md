# 🎵 Discord Navidrome Bot

Discord-бот для проигрывания музыки из вашего личного сервера **Navidrome** (Subsonic API). 
Бот использует **Lavalink** для стриминга аудио в голосовые каналы. Это обеспечивает стабильное воспроизведение, поддержку очереди и полную совместимость с современным протоколом шифрования голоса Discord (DAVE).

## ✨ Функционал

- 🔍 **Поиск и выбор треков**: Команда `/search` выводит топ-5 результатов из вашей медиатеки с кнопками для выбора нужного трека.
- 📻 **Воспроизведение**: Запуск музыки из Navidrome в текущем голосовом канале.
- 📋 **Очередь треков**: Добавление треков в очередь (`/queue`), пропуск текущего трека (`/skip`).
- ⏯️ **Управление**: Пауза (`/pause`), возобновление (`/resume`) и полная остановка с отключением от канала (`/stop`).
- 🎧 **Поддержка DAVE**: Благодаря Lavalink v4.2+, бот корректно работает с новым протоколом сквозного шифрования Discord.

## 🚀 Установка и запуск

### Предварительные требования

Убедитесь, что в вашей системе установлены:
- Python 3.10+
- Java 17+ (необходима для работы Lavalink)
- FFmpeg (рекомендуется)
- netcat (необходим для скрипта start.sh, в Arch Linux это openbsd-netcat)
- Navidrome (сервер с доступом к вашему аккаунту по API)

### 1. Клонирование репозитория

Откройте терминал и выполните:
git clone https://github.com/artemshurdukov/discord-navidrome-bot.git
cd discord-navidrome-bot

### 2. Настройка окружения Python

Создайте виртуальное окружение и установите зависимости:
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

### 3. Настройка переменных окружения

Скопируйте пример конфигурации и заполните его своими данными:
cp .env.example .env
nano .env

В файле .env укажите:
- DISCORD_TOKEN — токен вашего бота из Discord Developer Portal.
- NAVIDROME_URL — адрес вашего сервера Navidrome (например, http://localhost:4533).
- NAVIDROME_USER — логин пользователя Navidrome.
- NAVIDROME_PASS — пароль пользователя Navidrome.

### 4. Настройка Lavalink

В папке lavalink должен находиться файл application.yml. Убедитесь, что в нем указан правильный пароль.

Скачайте Lavalink.jar (версию 4.2.0 или выше) и положите его в папку lavalink.

### 5. Запуск

Вы можете запустить бота двумя способами: вручную (через два терминала) или с помощью готового скрипта.

Вариант А: Автоматический запуск (рекомендуется)
Проект включает в себя скрипт start.sh, который запускает Lavalink в фоне, ждет его готовности и затем запускает бота.

Выполните в корне проекта:
chmod +x start.sh
./start.sh

Скрипт сам запустит всё необходимое. При остановке бота (Ctrl+C) Lavalink также будет остановлен.

Вариант Б: Ручной запуск
Lavalink и бот должны работать одновременно. Откройте два терминала.

Терминал 1 (Lavalink):
cd lavalink
java -jar Lavalink.jar
Дождитесь сообщения "Lavalink is ready to accept connections".

Терминал 2 (Бот):
source venv/bin/activate
python bot.py

## 🎮 Команды бота

| Команда | Описание |
| :--- | :--- |
| /play <название> | Найти и сразу включить первый подходящий трек. (трек включается сразу в обход очереди) |
| /search <название> | Показать список из 5 треков с возможностью выбора через кнопки. (трек добавляется в конец очереди) |
| /queue | Показать текущую очередь треков. |
| /skip | Пропустить текущий трек. |
| /pause | Поставить воспроизведение на паузу. |
| /resume | Продолжить воспроизведение. |
| /stop | Остановить музыку и отключить бота от канала. |

## ⚠️ Важно

- Файл Lavalink.jar не хранится в репозитории (он слишком большой). Скачивайте его отдельно.
